# Workout Web App

This project is organized to ensure clarity, simplicity, and easy access to public content and workout resources.

## 📁 Folder Structure

All key resources are placed inside the `public` directory. Here's how it's organized:

public/
├── index.html
├── css/
│ └── styles.css
├── js/
│ └── script.js
├── images/
│ └── (all image assets)
├── workouts/
│ ├── workout1.html
│ ├── workout2.html
│ └── ... (all workout-related files)

- **`public/`**: Contains all publicly accessible files.
- **`public/workouts/`**: Dedicated folder for all workout routines and related pages.
- **`public/css/`**, **`js/`**, **`images/`**: Standard static resources.

## 📌 Guidelines

- Place **all files and folders inside `public/`**.
- Keep **all workout files exclusively in `public/workouts/`**.
